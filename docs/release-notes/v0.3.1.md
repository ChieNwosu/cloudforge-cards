# CloudForge Cards v0.3.1: Phase 4A Audio Polish Patch

**Live demo:** [https://cloudforge-cards.emergent.host/](https://cloudforge-cards.emergent.host/)

**Release date:** 2026-07-01

---

## Summary

v0.3.1 adds browser-native Professor Flock read-aloud across all learning and gameplay modes. This is a frontend-only audio quality patch. No external TTS APIs, no generated audio files, no backend audio routes. No scoring, grading, leaderboard, schema, or certification-content changes.

---

## Features

### Professor Flock Read-Aloud

- Browser-native text-to-speech using the Web Speech API (speechSynthesis)
- Read-aloud buttons appear on: Play scenario prompts, architect commentary, Test Mode questions, Test Mode review explanations, Match prompts, Match result explanations, and Learn Flashcards (front and back)
- Starting a new read-aloud automatically stops the previous speech
- Muting stops any current speech immediately

### Audio Toggle

- **Audio: On / Audio: Muted** global toggle in the navigation bar (desktop and mobile)
- Persistent mute preference stored in localStorage (key: `cloudforge_audio_muted`)
- When muted, read-aloud buttons show a disabled "Audio muted" state and do not play
- When speech synthesis is unavailable, buttons show a disabled "Audio unavailable" state and the global toggle hides itself

### Voice Style Selection

- Three voice styles: Professor, Calm, and Default
- Persistent voice style preference stored in localStorage (key: `cloudforge_voice_style`)
- Improved English voice selection using `speechSynthesis.getVoices()` with async `voiceschanged` handling
- Falls back gracefully if preferred voices are not available on the platform

### Spoken Text Cleanup

- Exam codes (e.g., "CLF/SAA") are expanded for natural pronunciation
- Slash-heavy phrases are cleaned up for smoother speech
- Markdown symbols and formatting artifacts are stripped
- Whitespace is normalized
- Label pauses are inserted for better comprehension

### Error Handling

- Warning-based error handling (no crashes if speech synthesis fails or is unavailable)
- Graceful degradation on browsers that do not support the Web Speech API
- No user-facing error messages unless the feature is completely unavailable

## What Was NOT Changed

- No backend routes, scoring logic, or grading logic
- No leaderboard behavior changes
- No database schema changes
- No certification content or exam-track changes
- No package dependency additions (uses built-in browser APIs only)
- No Play, Test, Match, or Learn gameplay logic changes

## Known Limitations

- Voice availability depends on the browser and operating system (some voices may not be available on all platforms)
- Mobile browsers may have limited or delayed voice loading
- Long text segments may have slight pauses between utterance chunks on some platforms
- No visual waveform or progress indicator during playback
- No speed/rate control exposed to the user yet
