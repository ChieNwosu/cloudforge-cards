# CloudForge Cards v0.3: Perpetual Learning

**Live demo:** [https://cloudforge-cards.emergent.host/](https://cloudforge-cards.emergent.host/)

## Phase 2: Test Mode (latest)

### Summary

v0.3 Phase 2 adds Test Mode to the Perpetual Learning hub. Players can now take 15-question quizzes with multiple choice, true/false, and scenario service-selection questions. Grading is server-side so answer keys are never shipped to the browser. After completing a quiz, players see a score screen with a count-up animation, review explanations for every question, and recommended review areas linking back to Learn Flashcards.

### Route Added

| Route | Purpose |
|-------|---------|
| `/learn/test` | 15-question quiz sessions with track filtering and server-side grading |

### Test Mode Features

- 15-question quiz sessions drawn from the service-card question bank
- Three question types: multiple choice, true/false, and scenario service-selection
- Server-side grading (POST answer to `/api/learn/test/grade`; answer keys never in frontend code)
- Track-filtered sessions: questions scoped to CLF/SAA, AIF, MLA, or Mixed
- Final score screen with count-up score animation
- Review explanations for each question (correct answer plus rationale)
- Recommended review areas based on missed questions
- Local best/latest score tracking per track (stored in localStorage)
- "Reinforce in Flashcards" button linking missed topics back to `/learn/cards`

### Endpoints

| Method | Path | Purpose |
|--------|------|---------|
| GET | `/api/learn/test/start?track=CLF_SAA` | Generate a 15-question quiz session |
| POST | `/api/learn/test/grade` | Grade a submitted answer (server-side) |

### Landing Page Update

The landing page now reflects v0.3 positioning with:
- Learn and Test CTAs alongside the Play CTA
- "Forge Your Cloud Mastery" tagline
- Updated feature description highlighting the study and testing modes

### Known Limitations (Phase 2)

- Question bank is generated from the existing 33 service cards; coverage is strongest for CLF/SAA
- AIF and MLA tracks have fewer questions due to smaller tagged card pool
- Local best/latest scores do not sync across devices (localStorage only)
- No spaced repetition or adaptive question selection yet
- Professor Flock does not yet generate AI explanations (static review text only)

## Phase 1: Learn Flashcards

### Summary

v0.3 Phase 1 adds the Perpetual Learning hub and Learn Flashcards mode to CloudForge Cards. Players can study AWS service cards in a Quizlet-style flashcard experience with exam-track filtering, category browsing, and local progress tracking.

---

## Routes Added

| Route | Purpose |
|-------|---------|
| `/learn` | Perpetual Learning hub with mode selector and track picker |
| `/learn/cards` | Learn Flashcards with flip animation, search, and progress |

Existing routes preserved:
- `/play` (3-round game)
- `/leaderboard` (session scores)
- `/how-to-play` (rules and scoring reference)

---

## Learn Flashcards Features

- Flip-card interaction showing service name on front, study content on back
- Back of card displays: description, use cases, common pairings, anti-patterns, study tip, exam tracks, and flashcard Q&A
- Exam-track selector: CLF/SAA, AIF, MLA, Mixed
- Category filter (All, Compute, Storage, Database, Network, Security, Analytics, Integration, Monitoring, AI)
- Full-text search across card titles and descriptions
- Local-only Known/Review progress stored in localStorage
- Clear progress button with confirmation
- Cards count badge showing visible/total

## Professor Flock Beta Avatar

Professor Flock now has a visual presence in the app. A beta avatar image is displayed on the Learn hub and alongside flashcard content. The avatar is served as a static asset at `/professor-flock.jpg`.

Professor Flock's role:
- Provides contextual hints during gameplay
- Appears as a learning companion in study modes
- Future phases will add AI-generated explanations powered by Professor Flock's persona

---

## Certification Prep as a Filter Layer

Certification Prep is a filter layer across learning content, not a separate engine or standalone mode. When a learner selects a track (CLF/SAA, AIF, MLA, or Mixed), only flashcards tagged for that track appear.

Current coverage:
- **CLF/SAA:** Strongest coverage. All 33 service cards have CLF/SAA-relevant content.
- **AIF:** Early beta. AI-related services (Bedrock, SageMaker, Lambda for inference) are tagged.
- **MLA:** Early beta. ML workflow services (SageMaker, S3 for data lakes, Glue) are tagged.

---

## Local-Only Progress

Known and Review progress is stored entirely in the browser's localStorage. No server-side persistence of study progress exists in this phase.

Implications:
- Progress resets if the user clears browser data
- Progress is device-specific (not synced across devices)
- A future account system (planned for v0.4+) will add server-side progress storage
