# Screenshots

This folder is reserved for future screenshots of CloudForge Cards.

## Planned Screenshots

When the app is running (locally or deployed), capture the following:

1. **Landing page:** The dark-theme hero section with game title and start button
2. **Deal phase:** A scenario card, constraint chips, and the service card hand
3. **Card selection:** A hand with 3 to 6 cards selected (highlighted)
4. **Score breakdown:** The full 6-sub-score feedback panel after submission
5. **Leaderboard:** The top scores table with player names and totals
6. **Professor Flock hint:** A hint displayed during gameplay
7. **Synergy highlight:** The score panel showing detected service pairings
8. **Mobile view:** Responsive layout on a phone-width viewport

## File Naming Convention

Use descriptive lowercase filenames with hyphens:

- `01-landing-page.png`
- `02-deal-phase.png`
- `03-card-selection.png`
- `04-score-breakdown.png`
- `05-leaderboard.png`
- `06-professor-flock-hint.png`
- `07-synergy-highlight.png`
- `08-mobile-view.png`

## Guidelines

- Capture at 1280x800 or higher resolution
- Use the dark theme (default) for all screenshots
- Do not include browser chrome (address bar, tabs) in screenshots
- Annotate with arrows or highlights only when necessary for documentation
- Optimize file size (PNG for UI, JPEG for photographic backgrounds)
- Do not fabricate or mockup screenshots; only use real application captures
