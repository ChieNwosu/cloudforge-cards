## Interpreting the Scores

The solo-run screenshots intentionally include different scores. They were captured to demonstrate how the scoring system handles partial fits, full matches, weak service selections, final summaries, and leaderboard behavior.

The scores shown are test examples across scenarios and should not be interpreted as a formal assessment of the creator's AWS knowledge.
