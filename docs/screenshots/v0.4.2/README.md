# v0.4.2 Screenshots

Screenshots captured from the v0.4.2 Track-Aware AWS Learning Platform release.

## Files Present

- `landing-page.jpg`: Landing page showing the CloudForge Cards hero, navigation, and CTAs

## Important Note

The landing page screenshot was captured before the hero stats section was updated to reflect v0.4.2 totals. The screenshot shows "30 service cards | 10 scenarios | 8 constraints" which represents an earlier version's stats. The actual v0.4.2 app has 60 service cards, 38 scenarios, and 8 constraints.

The visual design, navigation layout, dark theme, card illustrations, and feature descriptions shown in the screenshot are accurate for v0.4.2.

## Guidelines

- Capture from the live deployment at https://cloudforge-cards.emergent.host/
- Use the dark theme (default)
- Capture at 1280x800 or higher resolution
- Do not include browser chrome
- Do not fabricate or mockup screenshots; only use real application captures
- Optimize file size (JPG for photos, PNG for UI elements)
