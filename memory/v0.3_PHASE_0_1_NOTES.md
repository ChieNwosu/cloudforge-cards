# CloudForge Cards v0.3 - Phase 0 + Phase 1 (Perpetual Learning: Learn flashcards)

Date: 2026-06-28. Branch direction: feature/v0.3-learn-mode. Baseline: v0.2.6.1.

## Scope delivered
- Phase 0: additive Learn content layer. The 3-round game and v0.2.5 scoring engine are untouched.
- Phase 1: route-isolated Learn flashcard experience (hub + flashcards).

## Routes added
- /learn        Perpetual Learning hub ("Forge Your Cloud Mastery", track selector, mode cards)
- /learn/cards  Flashcards (flip, track + category filter, search, local known/review progress)
- Nav gained a "Learn" link (desktop + mobile). Play, Leaderboard, How to Play unchanged.

## Data fields added (additive, served only by Learn endpoints)
Per service card, via backend/learn_content.py enrich_cards():
- exam_tracks (default ["CLF_SAA"]; AIF+MLA only on bedrock, sagemaker; MLA also on s3, redshift,
  kinesis, athena, glue_catalog)
- domains (reserved, default [])
- use_cases, anti_patterns, study_tip (curated per card)
- common_pairings (auto-derived from the game's SYNERGIES; list of {id, title})
- flashcard_front (title), flashcard_back (description)
SERVICE_CARDS is NOT mutated; GET /api/cards/services (the game) returns the original cards.

## Backend endpoints (read-only)
- GET /api/learn/cards  -> { cards: [34 enriched], tracks: [CLF_SAA, AIF, MLA] }
- GET /api/learn/tracks -> { tracks }

## Frontend
- Pages: LearnHub.jsx, LearnCards.jsx. Component: FlockAvatar.jsx (image + emoji fallback).
- Professor Flock beta art: /app/frontend/public/professor-flock.jpg (42 KB, lazy-loaded,
  rounded avatar; emoji 🦅 fallback if it fails). This is BETA art, not final v1.
- Local-only progress: localStorage cf_learn_track (selected track), cf_learn_progress
  ({serviceId: "known"|"review"}). No backend, no accounts.

## Intentionally deferred (not in this phase)
- Test mode, Match mode (placeholder "Coming soon" cards only, no routes).
- Full Certification Prep engine (it is a filter layer via the track selector).
- Audio, accounts, Microsoft Entra, Cognito, Bedrock, DynamoDB, SQLite/Postgres migration.

## Grading decision (for later phases)
Future Test and Match grading will be SERVER-SIDE so answer keys are not fully exposed in the
browser. Not implemented now; Learn needs no grading.

## Tests
- Backend pytest 32/32 pass (iteration_6): 8 new Learn tests + 14 game regression + 8 leaderboard.
- Scoring acceptance 5/5; static_blog ideal still ~90 Well-Architected; game card payload has no
  Learn-field leakage.
- Frontend smoke verified: hub render + Flock image, flip, search, track filter, AIF beta note,
  known/review marks, progress persists across reload, clear progress; no full-page horizontal
  overflow at 390px; clean 3-column desktop grid.

## Known limitations
- AIF/MLA flashcard banks are early beta (few honestly-tagged cards); labeled "more coming soon".
- Pre-existing P2 (unchanged): leaderboard add scans collection in-memory for name match; guest
  expires_at stored as ISO string (no native Mongo TTL index).

## Safety
- Safe to preview test: yes. Safe to redeploy later: yes (additive, route-isolated, all green).
- Reminder: production must have ADMIN_TOKEN set for leaderboard admin delete (unrelated to Learn).
