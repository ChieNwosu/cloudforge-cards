# CloudForge Cards v0.3 - Phase 2 (Perpetual Learning: Test Mode)

Date: 2026-06-30. Branch direction: feature/v0.3-test-mode. Baseline: v0.3 Phase 1.

## Scope delivered
- Test Mode: a 15-question quiz with SERVER-SIDE grading. Route-isolated and additive.
- The 3-round game, v0.2.5 scoring engine, leaderboard, and Learn Flashcards are untouched.

## Routes added
- /learn/test  (start screen -> quiz flow -> results + review)
- Learn hub "Test Mode" card now links to /learn/test. Match stays "coming soon".
  Certification Prep remains a filter layer (links to track-filtered flashcards).

## Endpoints added (answer keys never sent to the browser)
- GET  /api/learn/test/session?track=CLF_SAA -> { track, questions[15 sanitized], total, beta, pool_size }
- POST /api/learn/test/grade  { track, answers:[{question_id, selected}] }
      -> { score, correct_count, total, per_question[], strengths[], review_areas[], track }
  Grading is in backend/test_bank.py; `correct` is stripped from session responses.
  No user quiz history is stored on the server.

## Question types supported (MVP)
- mcq (single select), truefalse, scenario_select (select one or more services; exact-set grading).

## Question bank (backend/test_bank.py) and counts by track
- CLF_SAA: 16 questions (session serves a random 15)
- AIF: 5 questions (flagged early beta in session + results)
- MLA: 5 questions (flagged early beta)
- MIXED: combines all (26) and serves 15
Each question: question_id, prompt, question_type, answer_options[{id,text}], correct[] (server only),
explanation, exam_tracks[], domains[], related_services[], difficulty, professor_flock_hint.

## Track filtering
- Uses the Learn track from localStorage (cf_learn_track): CLF_SAA, AIF, MLA, MIXED.
- Limited tracks (AIF, MLA) show a friendly "early beta, more questions coming soon" note rather
  than hiding the mode.

## Local progress (localStorage only, no accounts/server)
- cf_test_progress: { [track]: { last, best, lastDate } }. Best score per track persists.

## Gamification
- Count-up score animation on results (requestAnimationFrame, low-risk).
- CSS-only confetti for score >= 80, gated by prefers-reduced-motion. No new dependency.

## Frontend files
- New: pages/LearnTest.jsx. Edited: App.js (route), pages/LearnHub.jsx (Test card link),
  lib/api.js (getTestSession, gradeTest), index.css (confetti keyframes). Reuses FlockAvatar.

## Deferred (not in this phase)

- Audio/background music, accounts/auth, Bedrock/Cognito/DynamoDB, DB migration.
- Larger AIF/MLA banks and full certification-prep expansion.
