# AWS Cloud Practitioner: Map of Content

This is the top-level Map of Content (MOC) for AWS Cloud Practitioner (CLF-C02) study notes as they relate to CloudForge Cards.

## Purpose

These notes serve two goals:
1. Organize CLF-C02 study topics into an interconnected knowledge graph
2. Connect each topic to CloudForge Cards gameplay (service cards, scenarios, constraints, hints)

## Domain Notes

- [[01_Cloud_Concepts]] - Cloud computing fundamentals, deployment models, value proposition
- [[02_IAM]] - Identity and Access Management, policies, roles, least privilege
- [[03_EC2]] - Elastic Compute Cloud, instance types, pricing models
- [[04_S3]] - Simple Storage Service, storage classes, durability, use cases
- [[05_Databases_Analytics]] - RDS, DynamoDB, Redshift, Athena, and analytics services
- [[06_Serverless]] - Lambda, Fargate, API Gateway, event-driven architecture
- [[07_Networking_VPC]] - VPC, subnets, CloudFront, Route 53, load balancing
- [[08_Security_Compliance]] - Shared responsibility, encryption, compliance programs
- [[09_Billing_Pricing]] - Pricing models, Cost Explorer, Budgets, free tier
- [[10_Well_Architected]] - Six pillars, design principles, trade-offs

## How to Use These Notes

Each domain note includes:
- A short summary of the topic
- Key concepts for CLF-C02 exam preparation
- CloudForge Cards integration ideas (which scenarios and cards relate)
- Related service cards from the game
- Potential scenario ideas for future game content
- Links to other notes in this graph

## CloudForge Cards Connection

These notes feed directly into the content pipeline described in the project documentation. Study concepts become:
- Service-card tooltips
- Professor Flock hints
- Scenario prompts and constraints
- Ideal architecture combinations
- Post-round reflection prompts

See [[docs/content-pipeline.md]] and [[docs/clf-knowledge-integration.md]] for the full integration plan.
