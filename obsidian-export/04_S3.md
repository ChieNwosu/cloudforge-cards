# S3 (Simple Storage Service)

## Summary

S3 is AWS's object storage service designed for 99.999999999% (11 nines) durability. It stores files as objects in buckets, with virtually unlimited storage capacity. S3 is one of the most versatile AWS services, used for everything from static website hosting to data lakes.

## Key Concepts

### Core Features

- **Objects:** Files stored in S3, consisting of data, metadata, and a unique key
- **Buckets:** Containers for objects. Bucket names are globally unique across all AWS accounts.
- **Unlimited Storage:** No practical limit on the number of objects or total storage
- **Object Size:** Individual objects can be up to 5 TB (use multipart upload for files over 100 MB)

### Storage Classes

- **S3 Standard:** Frequently accessed data. High availability (99.99%). Default choice.
- **S3 Standard-IA (Infrequent Access):** Lower cost for data accessed less often. Retrieval fee applies.
- **S3 One Zone-IA:** Same as IA but stored in a single AZ. Lower cost, lower resilience.
- **S3 Glacier Instant Retrieval:** Archive with millisecond retrieval. Quarterly access pattern.
- **S3 Glacier Flexible Retrieval:** Archive with minutes-to-hours retrieval. Annual access pattern.
- **S3 Glacier Deep Archive:** Cheapest storage. 12-hour retrieval. Compliance archives.
- **S3 Intelligent-Tiering:** Automatically moves objects between tiers based on access patterns.

### Security and Access Control

- **Bucket Policies:** JSON policies attached to a bucket controlling access
- **ACLs (Access Control Lists):** Legacy per-object access control (prefer bucket policies)
- **Block Public Access:** Account-level or bucket-level setting to prevent accidental public exposure
- **Encryption:** Server-side encryption (SSE-S3, SSE-KMS, SSE-C) or client-side encryption

### Key Use Cases

- Static website hosting (HTML, CSS, JS served directly from S3)
- Data lake foundation (store raw data, query with Athena)
- Backup and disaster recovery
- Application asset storage (images, videos, documents)
- Log storage and archival

### Versioning and Lifecycle

- **Versioning:** Keep multiple versions of an object. Protects against accidental deletion.
- **Lifecycle Rules:** Automatically transition objects between storage classes or delete them after a defined period.
